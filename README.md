## Learning Path

A practical progression for this collection is:

1. **Start with host discovery** — identify systems and basic network information.
2. **Practice port scanning** — learn how exposed ports reveal potential services.
3. **Read scan results** — interpret discovered ports and service information.
4. **Perform version enumeration** — identify useful service and version details.
5. **Move to web reconnaissance** — investigate HTTP services and web resources.
6. **Search for hidden content** — practice directory and file discovery with Dirb.
7. **Investigate SSH** — understand how exposed services contribute to reconnaissance.
8. **Combine the techniques** — build a structured reconnaissance workflow.
